How to use the guides

  1. Find the salary nearest yours in the jump table and open its guide for a line-by-line breakdown.
  2. If you live in Scotland, use the Scotland column or a Scottish guide. Only income tax differs; NI is UK-wide.
  3. Add a student loan or pension using the plan guides or the calculator.
  4. Check the result against your payslip. If the tax line differs, check your tax code first.

Common questions

Why does my payslip differ from the guide? Guides use an annual model with tax code 1257L. Payroll works per pay period, so a bonus, overtime, an emergency code or a mid-year start changes individual payslips even when the year’s total ends up close.

Which guide covers Wales? The rest-of-UK guides. The Welsh rates of income tax currently match England and Northern Ireland.

How often are the guides checked? Before every tax year and after any mid-year change. See the editorial policy.
